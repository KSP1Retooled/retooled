# KSP Retooled Releases & Issue Tracker

KSP Retooled is a community made continuation of Kerbal Space Program.
It is to bring KSP into the modern age, with Unity 6.7 and various performance
improvements that can be made more easily now that we can directly change KSP's
source.

* Want to install Retooled? [Download the launcher](https://github.com/KSP1Retooled/launcher/releases).
* Running into an issue? [Make a bug report](https://github.com/KSP1Retooled/retooled/issues).

This repository is the public issue tracker for KSP Retooled. It also hosts the
public release artifacts, though you will need to launcher in order to install
them.
